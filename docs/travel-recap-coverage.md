# 超域旅行年度回顾 Web 覆盖清单

来源设计文档：`/Volumes/Store/Code/self/astria/docs/official-services/travel-annual-recap-design.md`

## 已接入展示

### 统计窗口与隐私

- 最近 365 天滚动窗口：封面、分享总结。
- 全部历史用于跨窗口推导：第 0 页、对比与小结、数据覆盖。
- 账号整体视角：年度总览、分享总结。
- 展示角色名：第一束以太、角色高光、当前状态。
- 分享卡只保留玩家可读故事与可分享称号。
- 历史回溯完整性与最近同步：当前状态、数据覆盖。

### 订单与总览规模

- 年度订单总数：封面。
- 出发尝试次数：官方提示。
- 成功出发次数：封面、分享总结。
- 返回原服次数：归途统计。
- 成功完成订单数：以太倔强派。
- 执行中订单数：官方提示。
- 失败或异常订单数：官方提示。
- 预检失败次数：年度总览、官方提示。
- 涉及角色数：年度总览。
- 涉及子账号数：年度总览。
- 来源服务器数：年度航线。
- 目标服务器数：旅行版图、最常去的地方。
- 目标大区数：旅行版图。
- 第一笔订单：第一束以太。
- 最后一笔订单：最后一笔。
- 有记录月份数：年度总览。
- 活跃天数：封面、年度总览。

### 路线与目的地

- 最常目标服务器：最常去的地方、分享总结。
- 最常目标大区：旅行版图。
- 最常路线：年度航线。
- 来源服务器分布摘要：年度航线。
- 目标服务器覆盖：旅行版图、最常去的地方。
- 最常目标占比：最常去的地方。
- 家服务器推导：年度航线。

### 角色画像

- 旅行次数最多角色：角色高光。
- 返回次数最多角色：角色高光。
- 目标服务器最分散角色：角色高光。
- 最专一角色：专一以太体质。
- 当前推测仍在目标服角色：当前状态。
- 最近一次异常角色：专一以太体质。

### 时间习惯

- 最常下单月份：时间人格。
- 最常下单星期几：时间人格。
- 最常下单小时段：时间人格。
- 最密集旅行日：时间人格。
- 最长连续活跃窗口：深夜片段。
- 年度最晚出发：最后一笔、深夜片段。
- 深夜占比：深夜片段。

### 停留与归途

- 年度最长估算停留：最长停靠。
- 年度最快返程：最长停靠。
- 官方强制遣返次数：归途统计、自动遣返。
- 被强制遣返最多角色：自动遣返。
- 最容易睡过头目标服务器：自动遣返。
- 未找到返程/待确认片段：最长停靠。
- 旅行结束状态次数：自动遣返。
- 主动返程、自动遣返、至今未归三结局：归途统计。

### 成功、异常与官方提示

- 成功完成旅行/返回订单：以太倔强派。
- 出发尝试、成功出发、预检失败：官方提示。
- 执行中订单：官方提示。
- 失败或异常订单：官方提示。
- 异常原因 Top：官方提示脚注。
- 失败后 24 小时内重试成功：以太倔强派。
- 官方水晶折磨指数：官方水晶脾气、官方门卫。
- 按钮手癖：年度按钮手癖。
- 最快重试间隔：年度按钮手癖。
- 单日最高尝试：年度按钮手癖、登录器宇宙。

### 当前状态与数据完整性

- 当前仍在目标服角色列表摘要：当前状态。
- 已返回原服角色数量：当前状态。
- 未知状态角色数量：当前状态。
- 最近同步时间：当前状态、数据覆盖。
- 历史回溯完整性：数据覆盖。

### 对比、彩蛋与自检

- 环比变化：对比与小结。
- 同比变化：对比与小结。
- 历史最高：对比与小结。
- 2019 免费转服彩蛋：第 0 页。
- 鸟区晚高峰：鸟区晚高峰。
- 最长空窗：最长空窗。
- 数据质量检查留在 App 与开发文档，不进入玩家页面。

- 深夜水晶师：深夜片段。

- 这些文案不直接点名其他游戏，只保留玩家能会心一笑的语气。

## Web 事件

- `recap-ready`
- `recap-payload-accepted`：包含 `slideCount`、`coreSlideCount`、`optionalSlideCount`。
- `recap-payload-rejected`
- `recap-slide-changed`
- `share-image-created`
- `share-image-failed`

## App 接入契约

- Payload schema：`docs/recap-payload.schema.json`。
- 最小核心页样例：`docs/recap-payload-example-minimal.json`。
- 完整条件页样例：`docs/recap-payload-example-full.json`。
- WKWebView 对接说明：`docs/wkwebview-integration.md`。
- 条件分镜字段：`optional`、`priority`、`triggerReason`、`emptyBehavior`。
- 分享图风格字段：`shareCard.variant`，当前支持 `standard`、`chocobo-rush`、`zero-page`、`gatekeeper`、`quiet-window`。

## 调试入口

- `/recap/travel/embed?demo=1`：移动端完整 demo。
- `/recap/travel/embed?demo=minimal`：移动端核心页 demo。
- `/recap/travel/embed?debug=invalid`：payload rejected 状态。
